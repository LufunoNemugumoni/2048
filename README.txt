AUTONOMOUS SYSTEMS AND ROBOTICS 700
Intelligent Autonomous Robotic Systems Project
================================================

PROJECT STATUS / IMPORTANT LIMITATION — WEBOTS R2018b TARGET
-------------------------------------
This package contains reproducible Python-based reference simulations, plots, CSV logs,
Webots world/controller starter files, and a generated 3–9 page PDF report draft.

The results currently included were generated by the Python reference simulators in this
package, NOT by executing Webots. Webots is not installed or executed by this build process,
so Webots world/controller compatibility and live sensor/motor integration still require
verification on the student's machine. Do not describe Python reference-simulation results
as Webots results. The report explicitly records this limitation.

No ROS or Gazebo is used.

SOFTWARE
--------
Recommended:
- Python 3.10–3.12 for the standalone Python reference simulations
- Webots R2018b (target version requested by student; world syntax adjusted toward R2018b, but opening/runtime compatibility remains unverified)
- numpy
- matplotlib
- scikit-learn (optional; neural network training/evaluation)
- opencv-python (optional; camera image preprocessing demonstration)
- reportlab (only needed to regenerate the PDF report)

Install Python dependencies:
    python -m pip install numpy matplotlib scikit-learn opencv-python reportlab

Run the reproducible reference simulations from the project root:
    python Component_A/run_component_a.py
    python Component_B/run_component_b.py
    python run_all.py

Outputs are written to results/component_a and results/component_b. Plots are made with
Matplotlib. Random seeds are fixed in the scripts.

WEBOTS STARTER FILES
--------------------
Component A world:
    webots/component_a/worlds/navigation_world.wbt
Controller:
    webots/component_a/controllers/autonomous_controller/autonomous_controller.py

Component B world:
    webots/component_b/worlds/swarm_world.wbt
Controller:
    webots/component_b/controllers/swarm_controller/swarm_controller.py

Open a .wbt file in Webots. These files are intentionally starter templates; depending on
the Webots release, device names, PROTO availability, and controller configuration may need
adjustment. Copy or configure the controller folder in the Webots project structure if
Webots reports a missing controller. Validate that the world opens, then inspect the robot
devices and controller timestep before using live results in a submission.

PROJECT CONTENTS
----------------
Component_A/
  run_component_a.py     grid world, Dijkstra, A*, simple closed-loop differential-drive model,
                         synthetic LiDAR/camera fusion demonstration, metrics and plots
Component_B/
  run_component_b.py     3-agent coverage/task assignment, average consensus, PSO, neural
                         network classifier (scikit-learn if available; deterministic fallback),
                         metrics and plots
dataset/
  synthetic_sensor_dataset.csv
  synthetic_navigation_training.csv
results/
  CSV metric logs and Matplotlib PNG plots
report/final_report.pdf
  generated report draft; review, personalize, and update after running Webots
run_all.py
  runs both Python reference simulations

EXPECTED RUNTIME
----------------
Typically under one minute on a modern laptop; first-time package installation is separate.
Hardware: ordinary Windows 11/macOS/Linux laptop; no GPU required.
